# PhishScope — ALEPH Subject 13 (BR-B)

**공개 앱:** https://aleph-subject-13.vercel.app/  
**포트폴리오:** https://aleph-subject-12.vercel.app/

10번 연구 「피싱 웹사이트 탐지에서 입력 특징을 줄이면 분류 성능은 얼마나 달라지는가?」의 결과를 직접 비교하는 교육용 웹 앱입니다. 보안 학습자가 **특징 집합이 달라질 때 피싱 미탐(FN)과 정상 오경보(FP)가 어떻게 바뀌는지** 1분 안에 이해하고 직접 체험할 수 있습니다.

## 사용자가 해볼 일 3가지

1. **논문 결과 비교:** URL 8특징, URL+SSL 9특징, 전체 30특징 버튼을 차례로 누르고 F1·미탐·오경보를 비교합니다.
2. **가중 오류 비교:** 피싱 미탐 가중치를 1배, 10배, 20배로 바꿔 **FN × 가중치 + FP** 계산값과 최저값을 확인합니다.
3. **URL 표기 관찰:** 일반형·혼동형·IP형 예시를 선택하고 직접 HTTP(S) URL을 입력해 표기 신호를 확인합니다. 잘못된 URL과 지원하지 않는 스킴을 입력하면 오류 안내만 표시됩니다.

## 실행

이 저장소의 **`index.html`은 모든 CSS·JavaScript를 포함한 단일 정적 파일**입니다. 새 임시 폴더에 `index.html`만 저장해 브라우저에서 열거나, 저장소를 ZIP으로 받은 후 `index.html`을 더블클릭해 실행하면 됩니다. 추가 설치·계정·API 키·환경 변수·빌드 명령이 필요하지 않습니다. 소스에 URL을 외부 전송하는 통신은 없습니다.

간단한 로컬 서버를 원할 때는 `python -m http.server 8000` 실행 후 `http://localhost:8000`에 접속하세요.

## 자동 검증

Node.js 20 이상이 있다면 저장소 루트에서 `node --test test/smoke.test.cjs`를 실행하세요. 단일 HTML 내부의 원 논문 수치·계산·URL 오류 처리를 점검하는 8개 테스트입니다. 단, 자동 테스트는 실제 브라우저의 로그인 없는 접속 증거를 대신하지 않습니다.

## 논문 근거 (UCI 2015 데이터 중 450건 표본)

| 입력 집합 | 피싱 F1 | TP | FN | FP | TN |
|---|---:|---:|---:|---:|---:|
| URL 표기 8특징 | 0.688 | 139 | 44 | 82 | 185 |
| URL+SSL 9특징 | 0.875 | 158 | 25 | 20 | 247 |
| 전체 30특징 | 0.914 | 164 | 19 | 12 | 255 |

이는 논문의 동일 450건 OOF(out-of-fold) 결과를 표시한 것으로, **최신 URL의 실제 피싱 탐지 결과가 아닙니다.** URL 단서 관찰 기능은 문자열 기반 교육용 예시이며, 논문의 학습된 로지스틱 회귀 분류기를 재실행하거나 URL의 안전 여부를 판정하지 않습니다. HTTPS나 SSL 존재만으로 안전을 보증하지도 않습니다.

## 개인정보 및 보안 범위

- 연습용 `.example` 도메인과 문서용 IP `192.0.2.18` 사용
- 실제 사용자 계정·연락처·개인정보·암호·토큰·API 키 및 비밀 설정 미포함
- URL 조회, 백엔드 전송, 쿠키·분석 SDK, 저장소 접근 및 수집 기능 없음
- 외부 사이트에 접속하거나 악성 링크를 분석·차단하는 **실전 보안 제품이 아님**

## BR-B 검증 및 아직 필요한 증거

- 앱 구조와 수치, 입력 오류 처리는 기존 로컬 자동 검사 8개 및 브라우저 화면 검증 기록에 근거합니다.
- Vercel 배포는 프로덕션 `READY` 확인 완료. **사용자 브라우저의 새 시크릿 창 무인증 접속 확인**은 별도 확인해야 합니다.
- 과제 A 대표작은 위 앱 URL로 연결했고, 과제 A Production 배포도 확인했습니다.
- **BRB-C11**: 처음 보는 동료가 직접 사용한 **이름 없는 한 줄 감상**을 아직 받지 않았습니다. 실제 피드백만 제출합니다.
- 마지막 A의 공식 확정 여부는 사용자로부터 완료되었다는 보고를 받았습니다.
